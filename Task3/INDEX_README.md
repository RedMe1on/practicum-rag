# Векторный индекс базы знаний Cyberpunk Wiki

## Описание

Векторный индекс создан для семантического поиска по 28 статьям Cyberpunk Wiki.
Индекс позволяет находить релевантные фрагменты текста по пользовательским запросам
и используется в RAG-боте для поиска контекста.

## Модель эмбеддингов

| Параметр | Значение |
|----------|----------|
| **Модель** | `intfloat/e5-large-v2` |
| **Репозиторий** | https://huggingface.co/intfloat/e5-large-v2 |
| **Размер эмбеддинга** | 1024 |
| **Тип** | Sentence Transformer (contrastive learning) |
| **Префикс для документов** | `passage: <text>` |
| **Префикс для запросов** | `query: <text>` |

## База знаний

| Параметр | Значение |
|----------|----------|
| **Источник** | `cyberpunk_pages_modified/` (28 .txt файлов) |
| **Тематика** | Cyberpunk 2077 wiki (персонажи, корпорации, технологии, локации) |
| **Общий объём** | ~28 статей |

## Чанкизация

| Параметр | Значение |
|----------|----------|
| **Инструмент** | `RecursiveCharacterTextSplitter` (LangChain) |
| **Размер чанка** | 750 символов (~500-1000 токенов) |
| **Перекрытие** | 100 символов |
| **Разделители** | `\n\n`, `\n`, `. `, ` `, `""` |
| **Всего чанков** | **926** |

## Векторная база данных

| Параметр | Значение |
|----------|----------|
| **Тип** | ChromaDB (PersistentClient) |
| **Метрика** | Cosine similarity |
| **Коллекция** | `cyberpunk_knowledge` |
| **Расположение** | `chroma_index_db/` |

## Метаданные чанков

Каждый чанк хранит:
- `source_file` — имя исходного файла (напр. `Johnny_Silverhand.txt`)
- `chunk_index` — порядковый номер чанка в документе
- `total_chunks` — общее число чанков в документе
- `id` — уникальный идентификатор (напр. `Johnny_Silverhand_chunk_001`)

## Время генерации

| Этап | Время |
|------|-------|
| Загрузка модели | ~4 сек |
| Чанкизация документов | ~0.04 сек |
| Генерация эмбеддингов (926 чанков) | ~10 мин (602 сек) |
| Создание ChromaDB индекса | ~1.3 сек |
| **Итого** | **~10.1 мин (607 сек)** |

## Результаты тестовых запросов

> **Примечание:** Запросы выполнялись к индексу, построенному на текстах со словарём замен
> (Cyberpunk → Sci-Fi). Например: `Night City` → `Void City`, `Johnny Silverhand` → `Zyron Silvervein`,
> `Arasaka` → `Xarasaka`, `Cyberware` → `Synthware`.

### Query 1: "Zyron Silvervein?"
| Rank | Источник | Chunk | Distance | Similarity |
|------|----------|-------|----------|------------|
| 1 | Johnny_Silverhand.txt | 0 | 0.1623 | 83.8% |
| 2 | Johnny_Silverhand.txt | 37 | 0.1684 | 83.2% |
| 3 | Johnny_Silverhand.txt | 5 | 0.1765 | 82.4% |

**Оценка:** Все 3 результата из правильного файла (Johnny_Silverhand.txt).
Чанк 0 содержит ключевое введение персонажа, чанк 37 — записку из базы данных 2177,
чанк 5 — историю смены имени. Дистанции чуть выше, чем у оригинальных текстов (~0.16 vs ~0.13),
поскольку словарь замен вносит «шум» — модель E5 не обучена на Sci-Fi терминах.

### Query 2: "What is cyberware and how does it work?"
| Rank | Источник | Chunk | Distance | Similarity |
|------|----------|-------|----------|------------|
| 1 | Cyberware.txt | 1 | 0.1549 | 84.5% |
| 2 | Cyberware.txt | 2 | 0.1585 | 84.2% |
| 3 | Cyberware.txt | 3 | 0.1641 | 83.6% |

**Оценка:** Все 3 результата из Cyberware.txt. Модель корректно находит, несмотря на то что
в тексте `Cyberware` заменено на `Synthware`, а `Night City` на `Void City`.
Запрос использует оригинальный термин «cyberware», а в текстах он заменён на «synthware» —
это незначительно снижает релевантность, но семантическая близость сохраняется.
Чанки охватывают: определение, обзор, кибермоду.

### Query 3: "What corporations exist in Night City?"
| Rank | Источник | Chunk | Distance | Similarity |
|------|----------|-------|----------|------------|
| 1 | Night_City.txt | 13 | 0.1553 | 84.5% |
| 2 | Arasaka.txt | 124 | 0.1810 | 81.9% |
| 3 | Night_City.txt | 12 | 0.1831 | 81.7% |

**Оценка:** Чанк 13 (Night_City.txt) — лучший результат, содержит раздел «Corporations»
со списком Big 5 Employers: Xarasaka, Militrex, BioSynthetica, Kryon Tech, Night Corp.
Чанк 124 (Arasaka.txt) — менее релевантен (содержит ссылки на источники).
Чанк 12 (Night_City.txt) — введение в экономику Void City.
Запрос использует «Night City», но в текстах заменено на «Void City» — модель всё равно
находит релевантные чанки благодаря семантическому поиску.

### Вывод по качеству поиска

| Метрика | Оригинальные тексты | Тексты со словарём |
|---------|--------------------|--------------------|
| Средняя дистанция (Query 1) | 0.135 | 0.169 |
| Средняя дистанция (Query 2) | 0.141 | 0.159 |
| Средняя дистанция (Query 3) | 0.143 | 0.173 |
| % результатов из правильного файла | 100% | 100% |

**Итог:** Словарь замен незначительно ухудшает дистанции (~+0.02–0.03), но **не влияет
на релевантность** — все топовые результаты остаются из правильных источников.
Модель E5-large-v2 устойчива к лексическим заменам благодаря семантическому пониманию.
